# Research contract

The objective is a substantial improvement beyond all existing quasi-Riemann
thresholds and candidates. Decimal retuning near an existing contact is not the
objective. Work directly; delegate only when the user explicitly requests it.

Read `docs/STATE.md`, `sources.lock.json`, and the relevant research note before
starting. Refresh the tracker main branch and open PRs before a novelty claim.
Keep upstream source attributions and exact pins. Preserve previous work.

Separate an unconditional L-function theorem, a theorem about an exponent model,
an exact arithmetic certificate, a numerical experiment, and an unproved analytic
input. An optimistic model is not a zero-free half-plane result. Record the exact
missing implication. Never introduce an axiom or a source-provider assumption and
present the result as an unconditional improvement.

Prefer structural bottlenecks, explicit lemma contracts and falsifiable tests.
Checkpoint reproducible progress. Park a failed route with its reason and the new
fact needed to reopen it. Update `docs/STATE.md` and the README when scope changes.

Run `make verify` for the research certificates. Run `make sources` when pinned
upstream evidence changes. Only claim Lean or independent-kernel verification if
it actually ran on the stated source closure. Do not submit a bound to a leaderboard
without a complete checked proof. Routine research commits and pushes to this
repository are authorized by its creation request.
